# ACM-VNIT static HTML conversion

This is a standalone HTML/CSS/JavaScript conversion of the uploaded Figma Make project.

Entry point: `index.html`

Pages:
- `about.html`
- `impact.html`
- `domains.html`
- `events.html`
- `projects.html`
- `team.html`
- `contact.html`

No React/Vite runtime is required.

Open locally with a static server, e.g.:
`python3 -m http.server 8000`

Then visit:
`http://localhost:8000/`

Note: This conversion provides a static HTML implementation and preserves the broad generated visual direction and interactions. React-specific behavior/data rendering from the original TSX may require further page-by-page refinement if exact pixel parity is required.
